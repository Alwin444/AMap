# AMap

A sleek, GUI-driven **Network Mapping and Analysis Desktop Application** built with **Python (PySide6)**.

---

## 🚀 Features

### 🔍 Network Analysis
- ARP / IP Device Discovery  
- Port Scanning
- Speed Test  
- Real-time Traffic Monitoring  

### 🌐 Web Intelligence
- DNS Lookup  
- WHOIS Queries  
- SSL Certificate Checker  
- Traceroute  

### 🛠 Utilities
- PCAP Import / Export  
- Internet Speed Test  
- System Uptime Dashboard  

---

## 🖥️ Tech Stack

- Python 3.x  
- PyQT5 (GUI Framework) 
- Scapy (Libarary for packet based operation)

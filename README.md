# AMap

A sleek, GUI-driven **Network and Web Analysis Desktop Application** built with **Python**.

---

## 🚀 Features

### 🔍 Network Analysis
- ARP / IP Device Discovery  
- Port Scanning
- Speed Test  
- Real-time Traffic Monitoring  

### 🌐 Web Intelligence
- DNS Lookup  
- WHOIS Queries  
- SSL Certificate Checker  
- Traceroute  


## 🖥️ Tech Stack

- Python 3.x  
- PyQT5 (GUI Framework) 
- Scapy (Libarary for packet based operation)
